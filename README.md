# gitdeck.nvim

Панель GitDeck для Neovim: все мои git-репозитории и их состояние одним взглядом.
Открывается под деревом NERDTree (если его нет — слева).

```
 GitDeck  14:05
▶git-test (main)          ↓2 ✎1
 hackathon-lab (main)     ↓1
 proj (dev)               ↑1
 Сервис заметок (main)    ⌂
 Enter перейти · r обновить
 s настройки · q скрыть
```

В скобках — ветка, за которой следит GitDeck (по умолчанию та, что открыта сейчас).

| Значок | Значит |
|---|---|
| `↓N` | на GitHub N новых коммитов — забрать (pull) |
| `↑N` | N моих коммитов не отправлены — отправить (push) |
| `✎N` | N файлов изменены, не закоммичены |
| `✓` | всё синхронно |
| `▶` | текущий репозиторий (где сейчас nvim) |
| `⌂` | репозиторий только на компьютере, на GitHub его нет |
| `…` | идёт проверка; если GitHub не ответил — повторяется сама каждые 30 с, пока не придёт статус |
| `? не связан` | GitHub есть, но ветка не связана с ним (`git push -u origin main`) |

Репозитории находятся сами: папки из списка `dirs` и их подпапки первого уровня, где есть `.git`.
Склонировал (`gh repo clone`) или создал (`git init`, `gh repo create`) — появится после обновления.
Лежит глубже или в другом месте — добавь через настройки.

## Настройки (s в панели)

Окно по центру экрана, как в lazygit.

- **Список репозиториев** (открывается по `s`, курсор — на репозитории, где стоял в панели) и ветка, за которой следит каждый. `Enter` — выбрать ветку, `a` — добавить репозиторий, `d` — убрать из списка, `q` — закрыть.
- **Ветка репозитория** (`Enter` на репозитории в списке, `Esc` — назад): список веток, `●` — отслеживаемая, `(текущая)` — открытая сейчас. Пока ничего не выбрано, отслеживается открытая. Выбранная ветка отслеживается, даже если открыта другая: `↓`/`↑` считаются для неё. Например, выбрал `main`, а работаешь в своей ветке: слияние PR в main на GitHub покажется как `↓N`.
  Если выбранной ветки нет на компьютере, `↓N` — сколько её коммитов на GitHub нет ни в одной твоей ветке.
- **+ Добавить репозиторий** — ввести путь к папке (Tab дополняет).
- **− Убрать из отслеживаемых** — репозиторий пропадёт из панели; вернуть — «Добавить репозиторий».
- **⏱ Проверять каждые: N мин** — `Enter` и ввести число минут (целое, от 1). Заменяет `interval` из `setup`.
- **Значки** — внизу окна расшифровка всех значков панели.

`✎N` всегда про открытую ветку (файлы на диске).
Выбор сохраняется в `~/.local/share/nvim/gitdeck.json`.

## Установка (vim-plug)

```vim
Plug 'alexsunder/gitdeck.nvim'
```

## Настройка

```vim
lua << EOF
require("gitdeck").setup({
  dirs = { "~/git-test", "~/Documents/Сервисы", "~/Documents/Projects" },
  interval = 5,          -- минут между автообновлениями (можно менять в окне настроек)
  fetch = true,          -- спрашивать GitHub о новом (git fetch)
  retry = 30,           -- секунд до повтора, если GitHub не ответил
  max_height = 15,       -- наибольшая высота панели (подстраивается под число репозиториев)
  open_on_start = true,  -- открывать при запуске nvim
})
EOF
```

## Команды и клавиши

| | |
|---|---|
| `:GitDeck` | открыть / закрыть панель |
| `:GitDeckRefresh` | обновить сейчас |
| `:GitDeckClose` | закрыть панель |
| `Enter` (в панели) | перейти в репозиторий (nvim и дерево) |
| `r` / `q` (в панели) | обновить / скрыть |
| `s` (в панели) | настройки: ветка, добавить, убрать |

С auto-session: добавить `"GitDeckClose"` в `pre_save_cmds`, чтобы панель не попадала в сессию.

Панель обновляется в фоне, даже когда закрыта, и сразу после `:G …` (fugitive), закрытия lazygit/терминала и возврата в окно терминала. Значок текущего репозитория для lualine (по желанию):
`function() return require("gitdeck").status() end`.

Требуется Neovim 0.10+ и git.
